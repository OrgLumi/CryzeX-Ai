## ✨ What is CryzeX AI?

CryzeX AI is more than an AI chatbot.

It is designed as a complete **AI-powered development environment** where you can describe what you want to build and let AI help plan, generate, edit, debug, test, and manage the project.

Example:

```text
Create a Minecraft Paper plugin called CryzeXTeams
for Minecraft 1.21.x with teams, GUI management,
permissions, configuration and MySQL support.
```

CryzeX AI can turn that request into a structured development project containing:

```text
CryzeXTeams/
├── pom.xml
├── README.md
├── src/
│   └── main/
│       ├── java/
│       │   └── com/cryzex/teams/
│       │       ├── CryzeXTeams.java
│       │       ├── commands/
│       │       ├── listeners/
│       │       ├── managers/
│       │       └── utils/
│       └── resources/
│           ├── plugin.yml
│           └── config.yml
├── Dockerfile
└── .env.example
```
